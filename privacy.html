Privacy Policy

Last updated: 2026-11-07

munntao-youtube is a private tool used only by its operator to manage the operator's own YouTube channels.

What it accesses

With the operator's permission, it uses the YouTube Data API to upload videos to the operator's own channels and to set their titles, descriptions, tags, thumbnails, captions and privacy settings. It reads channel information only to confirm it is working on the right channel.

What it stores

Access tokens are stored only on the operator's own computer. Nothing is stored on any server run by this tool.

Sharing

It does not collect data about other people, and it does not sell, share or transfer any data to third parties.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Open an issue at github.com/munn/munntao-youtube.
