Privacy Policy — Munntao Video Publisher

Last updated: 2026-11-08

Munntao Video Publisher ("the tool") is an internal command-line tool. Its only user is its operator, who uses it to publish videos to the operator's own YouTube channels.

YouTube API Services

The tool uses the YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (www.google.com/policies/privacy).

What information the tool accesses

With the permission the user grants through Google OAuth (scope https://www.googleapis.com/auth/youtube.force-ssl), the tool:

  • reads the signed-in channel's ID and handle, only to confirm it is working on the intended channel;
  • uploads videos and writes their title, description, tags, category, language, privacy status, scheduled publish time, synthetic-content disclosure, thumbnail and English captions;
  • reads the list of caption tracks on a video it is updating, only to avoid adding a duplicate English track;
  • reads a video's current status when updating it, only to keep its current privacy setting.

It does not access viewer data, comments, subscribers, analytics, or any other channel's data.

How the information is used, stored and shared

  • Channel ID and handle are used only during a run and are not saved.
  • The OAuth access and refresh tokens are stored only on the user's own computer, in a folder readable only by that user. The tool has no server and sends no data anywhere except to Google's YouTube API.
  • No information is shared with, sold to, or transferred to any third party, inside or outside the operator's organization.
  • The tool does not use cookies and does not place or read any information on users' devices or browsers, other than the token file described above.

How to revoke access and delete data

  • You can revoke the tool's access at any time from the Google security settings page: security.google.com/settings/security/permissions.
  • Deleting the token file on your computer removes all data the tool keeps. If you revoke access, the stored token stops working and is deleted from the computer within 7 days.
  • To request deletion or ask a question, open an issue at github.com/munn/munntao-youtube/issues.
