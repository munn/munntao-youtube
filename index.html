Munntao Video Publisher

Munntao Video Publisher is an internal command-line tool. Its operator uses it to publish videos to the operator's own YouTube channels. It uses the YouTube API Services (YouTube Data API v3).

It is not offered to the public. No one else can sign up, sign in or use it, and it has no web interface.

What it does

  • Uploads a finished video file to one of the operator's own channels (videos.insert).
  • Sets the video's title, description, tags, category, language, privacy status or scheduled publish time, and the altered-or-synthetic-content disclosure (videos.insert, videos.update).
  • Sets a custom thumbnail that the operator approved beforehand (thumbnails.set).
  • Adds an English caption track (captions.list, captions.insert).
  • Before every run, reads the signed-in channel's ID and handle (channels.list) and stops if it is not the channel the operator chose.

It does not read, analyze or store data about other channels, viewers, comments or analytics, and it does not show YouTube data to anyone.

How sign-in works

The operator signs in once per channel with Google OAuth and picks that channel. The access token is stored only on the operator's own computer. Access can be removed at any time from the Google security settings page: security.google.com/settings/security/permissions.
